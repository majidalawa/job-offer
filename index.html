📖 نبذة عامة عن الوظيفة

نبحث عن مطور واجهات أمامية متميز يتمتع بحس إبداعي وخبرة برمجية عميقة لقيادة تطوير الواجهات الحديثة لمنتجاتنا الرقمية وحلول الدفع والتجارة الإلكترونية. ستعمل مباشرة مع فرق المنتجات وهندسة السحاب لتحويل النماذج والمخططات التفاعلية إلى كود نظيف وسريع، متبنياً أحدث المعايير في الأداء والأمان.

🎯 المهام والمسؤوليات الرئيسية

  • تصميم وبناء واجهات مستخدم معقدة وسريعة الاستجابة بالاعتماد على React.js و TypeScript و Next.js.
  • ضمان أعلى معايير أداء الويب وتحسين مؤشرات أداء الويب الأساسية (Core Web Vitals).
  • بناء مكونات تصميم موحدة وقابلة لإعادة الاستخدام (Reusable Design System Components).
  • التكامل والربط مع خدمات الـ Backend عبر واجهات برمجة التطبيقات (RESTful APIs و GraphQL).
  • كتابة اختبارات جودة برمجية متكاملة (Unit & E2E Testing) لضمان متانة الكود.
  • إجراء مراجعات الأكواد (Code Reviews) وتقديم التوجيه التقني للمطورين الصاعدين في الفريق.

📋 المؤهلات والشروط المطلوبة

  • خبرة احترافية لا تقل عن 4 سنوات في تطوير الواجهات الأمامية للويب.
  • إتقان عميق لتقنيات JavaScript الحديثة (ES6+) ولغة TypeScript.
  • فهم قوي لمعمارية React، الـ Hooks، وإدارة الحالة (State Management).
  • مهارة متقدمة في استخدام Tailwind CSS وتطبيق مبادئ التصميم المتجاوب لكافة الشاشات.
  • معرفة عملية بنظام التحكم في الإصدارات Git وأدوات CI/CD.
  • شهادة جامعية (ليسانس أو ماستر) في الإعلام الآلي، هندسة البرمجيات، أو ما يعادلها من خبرة عملية معترف بها.

🛠️ المهارات التقنية المستهدفة

React 19 / 18 TypeScript Next.js Tailwind CSS REST APIs GraphQL Web Performance Git & GitHub Jest / Vitest

🎁 المزايا والحوافز

  • راتب شهري منافس (180,000 - 260,000 دج) يُحدد بناءً على تقييم المقابلة الفنية.
  • مرونة تامة في أسلوب العمل (نظام هجين يومين بالمكتب أو عمل كامل عن بعد).
  • تأمين صحي تكميلي شامل للموظف وعائلته.
  • علاوات سنوية تعتمد على تحقيق أهداف المشاريع.
  • أحدث عتاد عمل وحاسوب محمول عالي المواصفات (MacBook Pro / ThinkPad).
